# Changelog

## [1.0.0] - unreleased

The first version, for GNOME 42 to 51.

- Keeps the shell theme of the desktop on the lock screen, where GNOME switches User Themes off.
- Shows the wallpaper sharp: blur and brightness can be set.
- Puts the date above the time, hides AM and PM, moves the clock up and writes it larger and
  bold. Each of these has its own switch; the sizes, the font and the height can be set.
- Nothing runs while the screen is unlocked. Switched off while the screen is locked, it puts the
  lock screen back the way GNOME made it.
