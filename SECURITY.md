# Security

Alcatraz runs on the lock screen, so a problem in it matters. It does not touch the password
prompt or the way you unlock, but if you find a way in which it weakens the lock screen (it
shows something it should not, it lets input through, it keeps the screen from locking or from
unlocking), please do not open a public issue. Report it privately through GitHub's
"Report a vulnerability" button on the Security tab of https://github.com/saikatnjm/alcatraz.
